# プロセス間通信入門

目的：同じマシン上のプロセス同士がどうやってデータをやり取りするかを、カーネルの視点で理解する。Unix ソケットと比べながら、TCP ループバックとポートの仕組みも理解する。さらに、外から届くパケットを NAT とファイアウォールがどう扱うかを、テーブルを引く連なりとして理解する。

## 目次

1. [Unix ドメインソケット](01-unix-domain-socket.md)：ルーティングされない通信と、ソケットファイルの役割
2. [接続の仕組み](02-connection.md)：socket / bind / listen / connect / accept と待ち受けソケット
3. [カーネルとプロセス](03-kernel-and-process.md)：ユーザーモードとカーネルモード、データの2回コピー
4. [共有メモリ](04-shared-memory.md)：コピーをなくす仕組み
5. [排他制御とロック](05-locking.md)：mutex、セマフォ、アトミック命令、futex
6. [性能](06-performance.md)：通信速度が変わる条件、Unix ソケット / TCP / HTTP の遅延の実測と、Unix ソケットで HTTP を使う理由
7. [ソケットの共通の枠組み](07-socket-framework.md)：AF_UNIX と AF_INET の共通点と違い、ソケットが持つもの、ストリーム型とデータグラム型
8. [TCP ループバックとポート](08-tcp-loopback-and-port.md)：ループバックの仕組み、ポートの実体、fd との違い、4つの組による接続の区別
9. [カーネルの待ち受けソケットテーブル](09-listening-table.md)：辞書としての見方とハッシュ表の実体、nginx の実例、特権ポート
10. [ポートスキャン](10-port-scan.md)：待ち受けソケットテーブルを外から確かめる行為、open / closed / filtered の意味、スキャンは誰が送り、どこまで届くか（家庭の PC、公衆 Wi-Fi、クラウドの VM）
11. [NAT](11-nat.md)：グローバル IP とプライベート IP の付け替え、送信元 NAT と宛先 NAT、ポートフォワーディング、接続が中から始まる理由
12. [ファイアウォール](12-firewall.md)：ステートフル検査とデフォルト拒否、機能の一覧、置き場所、テーブルの管理で防げないこと
13. [表の整理](13-tables-overview.md)：テーブルの呼び分け、1つのパケットが通るテーブルの順番、その手前（DNS・ルーティング・ARP）の概要

## 前提

- Linux を前提に説明する。macOS では動作やサポート状況が異なる部分がある。
- 実測値と実例（6章、8〜10章）は macOS 上で取ったものである。
